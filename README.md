# Univ-Assignments
<h1> University Assingnment </h1>
Questions-

Students are participating in a quiz competition. The quiz organizers need a system to manage participants' answers for each round of the quiz. Each student's answer is recorded sequentially, and if an incorrect answer is given, the system should discard it (similar to undo operations). The organizers have decided to use a data structure for this purpose because of its LIFO (Last In, First Out) property.
: Add a student's answer to the stack. : Remove the last answer if it's incorrect. : Check the most recent answer submitted. : Check if the stack is empty (indicating no answers have been submitted yet). A series of student answers and operations to perform on the stack. After performing all operations, display the current state of the stack. Add answers to the stack. Remove the last answer if it is incorrect. Display the most recent answer using peek. Check if the stack is empty. Push answers: "Answer1", "Answer2", "Answer3". Pop the last answer. Peek the stack. Push "Answer4" and check if the stack is empty.
